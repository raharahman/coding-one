# Coding One · UAL Creative Computing 🐍

My weekly Python work for the **Coding One** unit (BSc Creative Computing, University of the Arts London). Where I could, I themed tasks around my matcha brand, Nat'Cho Matcha.

## Highlights
| File | What it does | Concepts |
|---|---|---|
| `week01_matcha_cafe_order.py` | Café till that prices an order, with a student discount | Variables, data types, f-strings, input, conditionals |
| `week02_even_odd_order_number.py` | Order-number prize draw, handling fractions | Conditionals, modulo, type conversion |
| `week04_loops_tasks.py` | Sum of multiples, letter counter, division by repeated subtraction | `for` / `while` loops, accumulators |
| `week05_functions.py` | Greeting with optional arguments, Pig Latin translator for words and sentences | Functions, default parameters, string building |
| `week05_fizzbuzz.py` | FizzBuzz | Functions, modulo |
| `week06_lists_tasks.py` | Multiply a list, word pairs, unique values, rotate a list, largest sub-array sum | Lists, nested loops, slicing, type checks |
| `week07_dictionaries_tasks.py` | NATO alphabet encoder/decoder, Caesar cipher, **binary search** | Dictionaries, reverse lookups, modular arithmetic, searching |
| `week08_tic_tac_toe.py` | Two-player tic-tac-toe with win and draw detection | Lists, tuples, functions, game loop |
| `week08_guessing_game.py` | Number guessing game that tracks guesses, plus a two-player chat-box mode | `random`, lists, `while` loops |
| `week08_recursive_even_odd.py` | Even or odd using recursion | Recursion, base cases |
| `week08_matcha_iced_latte.py` | Draws a Nat'Cho iced matcha latte | `turtle`, functions, polygons, fills |
| `week08_spirograph.py` | Colourful spirograph in the brand palette | `turtle`, loops, `random` |
| `week08_random_walker.py` | Random walk drawing | `turtle`, `random` |
| `week08_polygon.py` | Draws any regular polygon from its angle | Geometry, functions |
| `week08_modules.py` + `week06_multiply.py` | Imports my own function from another file | Modules, imports |

## Run
Python 3. Each file runs on its own: `python week01_matcha_cafe_order.py`
